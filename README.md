# CuidarPet

Sistema para uma Clinica Veterinária

## 📋 Pré-requisitos

Antes de começar, certifique-se de ter instalado em sua máquina:

* Node.js (versão 18 ou superior)
* npm 
* Git

Para verificar as versões instaladas:

```bash
node -v
npm -v
git --version
```

## 🚀 Clonando o Projeto

Clone o repositório para sua máquina local:

```bash
git clone https: https://github.com/Rebecavitoria45/CuidarPet_Front
```

Acesse a pasta do projeto:

```bash
cd cuidarpet-frontend
```

## 📦 Instalando Dependências

Instale todas as dependências do projeto:

### Com npm

```bash
npm install
```

## ▶️ Executando o Projeto
Atenção: Para que o FRONT se conecte com o Backend é necessário executar o projeto do link a seguir: https://github.com/Rebecavitoria45/CuidarPet

### Ambiente de Desenvolvimento

Com npm:

```bash
npm run dev
```


Após iniciar o servidor, acesse:

```text
http://localhost:5173
```
